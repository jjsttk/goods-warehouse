# Postman коллекция для Goods Warehouse API
## Переменные коллекции
Тесты рассчитаны на последовательное выполнение на чистой бд.
Перед использованием установите следующие переменные:

- `baseUrl` - значение базового URL API (по умолчанию: http://localhost:8080)
- `firstProductId`, `secondProductId`, `thirdProductId`, `firstOrderId` - устанавливаются автоматически по результату выполнения методов создания товаров (post), в дальнейшем используются для подстановки в качестве параметра в запросах (get, patch, delete).
